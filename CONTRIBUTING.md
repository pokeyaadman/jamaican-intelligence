# Contributing to Jamaican Intelligence

Thank you for helping improve the data. Our goal is careful, attributed, culturally respectful Jamaican language and heritage documentation.

## Public corrections

Use the **Report a data correction** issue template for non-sensitive, public corrections. Include a record ID, precise proposed correction and supporting source links. GitHub issues are public, so **never post** names of private contributors, personal contact details, government ID numbers, recordings without consent, private documents or culturally restricted information.

## New Patois submissions

Before submitting new terms, phrases or examples, ensure you are authorized to license the material for the intended uses. New language entries are not automatically published. We need provenance, context, orthographic variants and a fluent-language review. The current lexical beta is an adaptation of Wiktionary content under **CC BY-SA 4.0**, and adaptations of that subset must satisfy the applicable ShareAlike terms.

## Cultural and business submissions

These datasets are not accepting public GitHub issue submissions containing private owner or speaker records. Use a separately approved private consent/intake workflow when one becomes available. Business records require source terms and a dated operating-status check.

## Review policy

No submission is promoted to an authoritative release solely by an AI-generated statement, automated test or an owner's blanket attestation. Expert/owner checks and source rights are tracked separately. See `REVIEW_WORKFLOW.md` and `docs/RELEASE_POLICY.md`.
