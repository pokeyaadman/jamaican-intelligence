## Stage A — Evidence collection

1. Curate a diversity of genres (informal conversations, interviews, teaching, institutional speech, community heritage). Each video is independently cited; a channel URL is not a sample.
2. For each suitable adult-speaker recording, assess language usage only through permitted access.
3. Maintain `research/youtube/observation_intake_template.csv` for future *human reviewed* observations; do not ingest audiovisual material without documented rights.
4. Seek creator/rights-holder responses for any intended transcript/audio/AI training use, separately.
5. Expand a reviewable glossary only from attested words and authorized original summaries.

## Stage B — Review and source equity

1. Invite qualified Jamaican Creole speakers/linguists, including diaspora perspectives appropriately labelled.
2. Track orthography variants and usage register rather than imposing a single informal spelling.
3. Do not infer parish or demographics from an accent or channel title.
4. Review transcription, privacy, license compatibility and model-training permission as distinct columns.
5. Record independent reviewer sign-off and release owner approval.

## Stage C — Release

1. Preserve the published 30-word beta unchanged until a separate reviewed release PR.
2. The 30 new `LANG-000031`–`LANG-000060` entries remain staged in PR #2.
3. The YouTube source register is evidence discovery **only** and does not contribute new approved lexical/audio records yet.
4. Use GitHub CI to check source metadata and fail closed on accidental approval/rights claims.
5. For a production speech dataset, add separate consent audit, clip-level permissions, accessibility/withdrawal plan and explicit scope. Never equate a CC video licence with unrestricted rights in identifiable voices.

## Collection quality metrics (future)

- Source leads with a working URL and evidence link
- Adult/voluntary content suitability reviewed
- Number of actually listened-to source segments
- Number of human-approved lexical/grammatical observations
- Number of rights-cleared text samples and audio samples **reported separately**
- Number of separate explicit AI-training grants
- Reviewer agreement rate on orthography and meaning
- Time since last source link, licence and consent recheck
